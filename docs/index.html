Source: the daily "overall" series of pypistats.org, mirror downloads excluded. pypistats keeps 180 days.

The counts include CI and other automated installs, so they measure installs rather than users. A burst lasting a few days is usually such automated traffic. Installs from outside PyPI, such as conda-forge, are not counted.

"Curated" is a hand-picked list. "With dependents" adds the most-downloaded packages whose latest release requires a listed package, directly or through other dependents, according to the PyPI metadata in ClickPy (clickpy.clickhouse.com); a dependency declared only in an optional extra does not count. A dependent takes the category of the package it was found through. Icons are the GitHub organization or user that hosts the repository.
